# KubernetesSubmissions

Submissions for **DevOps with Kubernetes 2026** (University of Helsinki, MOOC.fi).

Course: https://courses.mooc.fi/org/uh-cs/courses/devops-with-kubernetes-2026

## Convention

- One directory per application.
- Each exercise has a GitHub **release** whose tag equals the exercise number (e.g. `1.1`).
- The link of each exercise below points to the release tag and the relevant directory.
- Each application has its own `README.md` explaining how to run it.

> Replace `TAG` links with the real ones once the release exists:
> `https://github.com/Walter25S/KubernetesSubmissions/tree/<tag>/<directory>`
